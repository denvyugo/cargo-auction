# AI Usage

## Подготовка

Инициирован проект, добавлены необходимые зависимости. Получены типы из файла Open-API-схемы 

## Планирование

Для агента был задан промпт для разработки плана по созданию приложения на заданном стеке, указаны маршруты, особенности использования моков вместо бэкенда.

После проверки плана приступил к реализации.

## Реализация

Агенты выполнили реализацию в отдельной ветке worktrees по шагам, с тестами и ревью. По завершению работы результат был перенесён в ветку master проекта (тестовый проект, в реальном была бы ветка задачи).

## Доработка

Добавил пару полей фильтрв для демонстрации.

В принципе, агенты собрали черновой вариант приложения.

Поработать надо с интерфейсом для улучшения UI/UX.

В коде выделить работу с фильтрами в отдельный виждет. Можно добавить хук для управления параметрами поиска.
